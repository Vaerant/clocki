# Clocki
Minimal tray time clock that logs sessions to ActivityWatch (bucket `aw-clockin_<hostname>`).

- `npm install`, then `npm run dev` (hot reload) or `npm start` (built)
- `npm run dist` builds the Windows installer into `dist/`
- Push a tag like `v1.0.0` to build and publish a GitHub release (see `.github/workflows/release.yml`)
